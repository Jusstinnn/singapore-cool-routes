## 🧭 About ShadeWalk

ShadeWalk is a web-based navigation platform designed for dense, humid, and rain-prone cities like Singapore.

Instead of only optimising for the shortest or fastest route, ShadeWalk focuses on:
- Shaded and sheltered pathways
- Heat and weather exposure reduction
- Comfort-first navigation
- Support for both walking and cycling

Our mission is simple: **make sustainable, human-centred travel easier and more enjoyable.**

---

## ✨ Key Features

- 🌥️ Shade-optimised walking routes  
- 🚲 Cycle-friendly routing (avoids indoor and mall pathways)  
- 🌧️ Weather-aware route planning  
- 📊 Comfort-based route scoring  
- 🌱 Sustainability-focused mobility design
